---
description: Start een nieuwe campagne — briefing, inzichten en drie concepten in één keer
---

Start het campagneproces voor de input in `briefing/ruwe-input.md`.

1. Zet eerst de `briefing-agent` in. Wacht op het resultaat.
2. Zet daarna de `inzicht-agent` en de `concept-agent` **in dezelfde beurt** in, zodat ze parallel draaien.
3. Vat daarna zelf samen: het doel in één zin, de drie concepten in één regel elk, jouw advies, en de open vragen die beantwoord moeten worden.
4. Stop daar. Vraag welk concept we uitwerken — ga niet door naar de kalender zonder dat antwoord.
